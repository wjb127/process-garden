# Process Garden

macOS용 Rust 프로세스 모니터. 로컬에서만 동작하며 서버·AI 호출·자동 종료·로그인 등록이 없다.

## 실행

```sh
cargo run --locked
```

앱 패키지: `bash scripts/bundle.sh` 후 `open 'dist/Process Garden.app'`.
최초 빌드는 네트워크와 Rust 툴체인이 필요하다. Cargo.lock으로 버전을 고정한다.

## 기능

- 프로젝트 경로 및 역할(에이전트/MCP/개발 도구/브라우저/가상 기기) 분류
- 프로세스 검색, CPU 또는 메모리 정렬, 부모와 직접 자식 탐색
- 최신순·오래된순·중요도순 정렬. 프로젝트별을 끄면 전체 검색 결과에서 정렬
- 체크박스·⌘ 클릭 선택, Shift 범위 선택, 검색 결과 전체 선택 및 확인 후 일괄 종료
- 최근 약 3분 RAM 추이 및 검색 결과 CPU/메모리 상위 3개 막대 차트
- 보호/주의/일반 중요도와 판단 근거 (업무상 필요 여부를 판정하는 AI 평가가 아님)
- 전체 RAM·스왑·프로세스 수 표시, 3초 간격 백그라운드 갱신
- 확인 후 단일 SIGTERM 종료, 최대 2초 후 실제 종료 여부 확인
- 일괄 종료는 각 대상을 순차 검증하며 실행. 대상 수에 따라 수집 갱신이 일시 지연될 수 있음
- PID·시작시각·실행 파일 재확인, 현재 앱과 조상·시스템·다른 사용자 보호

## 범위와 제약

현재 macOS 전용이며 시스템 한국어 글꼴을 로드한다. 권한에 따라 실행 파일/작업 경로가 안 보일 수 있다. 프로젝트 분류는 cwd/명령 인자에서 `/Project/` 경로를 찾는 휴리스틱이다. 인자 전문은 화면이나 파일에 기록하지 않는다.
RSS는 압축·스왑을 포함한 총 메모리가 아니다. 그룹 RSS 합은 공유 페이지를 중복 계산할 수 있고 CPU는 코어 사용에 따라 100%를 넘을 수 있다. 첫 CPU 표본은 다음 갱신부터 의미가 있다.
PPID=1은 고아 확정이 아니다. launchd 서비스는 종료 후 재시작될 수 있다. 자동실행 해제·트리 일괄 종료·SIGKILL은 제공하지 않는다.
종료 신원 확인 직후 OS가 PID를 재사용하는 극히 짧은 경쟁 구간은 일반 PID 신호 API의 한계로 남는다.

검증: `cargo test --locked` (분류, stale PID 거부, 자기 자신 보호, 생성한 sleep 프로세스 실제 종료).

## 배포

GitHub Release ZIP은 Apple Silicon macOS용 로컬 서명 앱이다. Apple 공증을 받지 않아 다른 Mac에서는 Gatekeeper 확인이 필요할 수 있다. Intel Mac과 다른 OS는 이번 배포에서 검증하지 않았다.
프로세스 목록·명령 인자·경로는 외부로 전송하지 않는다. 공개 저장소에는 소스만 포함하며 로컬 실행 화면은 포함하지 않는다.
