# Process Garden

macOS용 Rust 프로세스 모니터. 로컬에서만 동작하며 서버·AI 호출·자동 종료·로그인 등록이 없다.

## 실행

```sh
cargo run --locked
```

앱 패키지: `bash scripts/bundle.sh` 후 `open 'dist/Process Garden.app'`.
최초 빌드는 네트워크와 Rust 툴체인이 필요하다. Cargo.lock으로 버전을 고정한다.

## 기능

- 프로젝트 경로 및 역할(에이전트/MCP/개발 도구/브라우저/가상 기기) 분류
- 프로세스 검색, CPU 또는 메모리 정렬, 부모와 직접 자식 탐색
- 최신순·오래된순·중요도순 정렬. 프로젝트별을 끄면 전체 검색 결과에서 정렬
- 체크박스·⌘ 클릭 선택, Shift 범위 선택, 검색 결과 전체 선택 및 확인 후 일괄 종료
- 최근 약 3분 RAM 추이 및 검색 결과 CPU/메모리 상위 3개 막대 차트
- 남색 도시 지도: 프로젝트별 RSS 면적 분할, 건물별 CPU 빛 흐름, 클릭 상세/Command 클릭 선택
- 보호/주의/일반 중요도와 판단 근거 (업무상 필요 여부를 판정하는 AI 평가가 아님)
- 전체 RAM·스왑·프로세스 수 표시, 3초 간격 백그라운드 갱신
- 확인 후 단일 SIGTERM 종료, 최대 2초 후 실제 종료 여부 확인
- 일괄 종료는 각 대상을 순차 검증하며 실행. 대상 수에 따라 수집 갱신이 일시 지연될 수 있음
- PID·시작시각·실행 파일 재확인, 현재 앱과 조상·시스템·다른 사용자 보호

## 범위와 제약

현재 macOS 전용이며 시스템 한국어 글꼴을 로드한다. 권한에 따라 실행 파일/작업 경로가 안 보일 수 있다. 프로젝트 분류는 cwd/명령 인자에서 `/Project/` 경로를 찾는 휴리스틱이다. 인자 전문은 화면이나 파일에 기록하지 않는다.
RSS는 압축·스왑을 포함한 총 메모리가 아니다. 그룹 RSS 합은 공유 페이지를 중복 계산할 수 있고 CPU는 코어 사용에 따라 100%를 넘을 수 있다. 첫 CPU 표본은 다음 갱신부터 의미가 있다.
도시의 면적은 검색 결과 RSS를 기준으로 분할하고, 길·레이블·건물 여백은 시각적 표현이다. 최대 24개 구역과 구역당 12개 건물을 표시한다. 나머지 구역도 클릭해 반복해서 펼쳐볼 수 있다. 구역/건물 클릭은 클릭 당시 구성원의 PID·시작시각·실행파일로 목록을 좁히며, 새로 시작한 프로세스는 전체 지도에서 확인한다. 이전 구역/전체 지도로 복귀할 수 있다. 앱 번들·프로젝트·서비스 이름별로 분류한다. 3D 건물 토글은 지붕·옆면·층을 그리는 2.5D 표현이며 회전 가능한 3D 엔진은 아니다. CPU 빛 효과는 egui GPU 도형 렌더링이며 별도 커스텀 셰이더는 아니다. 포커스 상태에서는 최대 약 10fps로 갱신한다. 디스크 지도는 아직 포함하지 않는다.
PPID=1은 고아 확정이 아니다. launchd 서비스는 종료 후 재시작될 수 있다. 자동실행 해제·트리 일괄 종료·SIGKILL은 제공하지 않는다.
종료 신원 확인 직후 OS가 PID를 재사용하는 극히 짧은 경쟁 구간은 일반 PID 신호 API의 한계로 남는다.

검증: `cargo test --locked` (분류, stale PID 거부, 자기 자신 보호, 생성한 sleep 프로세스 실제 종료).

## 야간 건물과 리소스 기록

- 3D 건물 기본 화면은 서울 오피스 야경 스타일이다. 같은 크기의 건물 바닥에 RAM 로그 축 높이, CPU에 따른 노란 창문을 표시한다. 기존 평면 모드는 `3D 건물`을 끄면 사용할 수 있다.
- 휠 또는 ± 버튼으로 확대/축소, 빈 공간 드래그로 이동, 우클릭 드래그 또는 회전 버튼으로 회전한다. `전체 보기`는 카메라를 복원한다.
- `배치 편집`을 켜면 건물을 드래그해 옮길 수 있다. 수동 위치는 현재 앱 실행 중 유지되며 프로세스 소속이나 실행 상태를 바꾸지 않는다. `배치 초기화`는 수동 위치를 지운다.
- 외부 렌더링 엔진 없이 egui 투영 도형을 사용한다. 실제 GPU 깊이 버퍼 기반 3D는 아니며, 건물을 서로 겹치게 수동 배치하면 가림 순서에 한계가 있다.

- 3D 건물은 검회색 외벽과 노란 창문 조명이며 CPU 활동선이 아래에서 위로 이동한다.
- 지도는 같은 보기에서 5분간 구성원·면적·순서를 고정한다. 검색/분류/구역 탐색 변경은 즉시 재배치하며 창 크기 변경 시 비율은 유지하고 화면 크기에 맞춘다. 숫자와 CPU 조명은 계속 갱신한다. 종료된 건물은 다음 재배치까지 비활성 공간으로 남는다.
- 상단은 `프로세스 / 디스크 / 최근 1시간` 독립 탭으로 구성한다. 디스크 탭은 볼륨별 용량을, 최근 1시간 탭은 RAM → 디스크 여유 공간 → 스왑 → CPU 순서의 그래프를 표시한다. CPU는 전체 기기 기준 0–100%이며 첫 표본은 제외한다. 앱 실행 시점부터 수집하며 지난 기록을 소급 복원하지 않는다. 종료 요청 처리 시점을 표시하고, 60분을 넘긴 표본은 제거한다. 파일 기록이나 외부 전송은 없다.
- 연결된 볼륨별 여유/전체 용량을 표시한다. APFS 공유 볼륨 용량은 합산하지 않는다. 프로세스별 파일 용량 추정이나 디스크 파일 삭제는 제공하지 않는다.
- 자동 테스트에는 299초 동안 배치 유지/300초 재배치, 보기 변경, 1시간 기록 만료 및 시동 디스크 선택이 포함된다.

## 배포

GitHub Release ZIP은 Apple Silicon macOS용 로컬 서명 앱이다. Apple 공증을 받지 않아 다른 Mac에서는 Gatekeeper 확인이 필요할 수 있다. Intel Mac과 다른 OS는 이번 배포에서 검증하지 않았다.
프로세스 목록·명령 인자·경로는 외부로 전송하지 않는다. 공개 저장소에는 소스만 포함하며 로컬 실행 화면은 포함하지 않는다.
